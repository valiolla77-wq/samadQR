# ساخت و انتشار خودکار نسخه APK (GitHub Releases)

فایل‌های باینری APK به دلیل محدودیت حجم گیت‌هاب و بهترین الگوهای توسعه نباید به عنوان سورس‌کد در پوشه پروژه ذخیره شوند.

### نحوه انتشار خودکار نسخه جدید:
با هر بار Push کردن تغییرات یا تگ جدید (مانند `v1.3.0`) به مخزن، گردش کار خودکار **GitHub Actions** (`.github/workflows/release.yml`) فعال شده و اقدامات زیر را به صورت خودکار انجام می‌دهد:
1. کامپایل کامل پروژه
2. امضای دیجیتال با کلید ریلیز معتبر
3. نام‌گذاری نسخه بر اساس `app/build.gradle.kts`
4. ساخت خودکار یک Release رسمی در گیت‌هاب و پیوست کردن مستقیم فایل نصبی APK برای دانلود کاربران.
