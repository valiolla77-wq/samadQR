# Samad Food QR (بارکد و ژتون غذای سلف دانشگاه)

> ⚠️ **اطلاعیه مهم و سلب مسئولیت:**  
> این برنامه یک **ابزار دانشجویی غیررسمی (UNOFFICIAL Student Utility)** است و هیچ وابستگی، تاییدیه یا ارتباط رسمی با سازمان امور دانشجویان، صندوق رفاه، یا دانشگاه‌ها ندارد. این اپلیکیشن صرفاً جهت تسهیل نمایش بارکد، ثبت و دسترسی آفلاین به رزروهای غذای دانشجویان ایجاد شده است.

---

## 📱 امکانات برنامه
- نمایش بارکد و QR کد منطبق با گیت‌های سلف دانشگاه (نسخه ۲، استاندارد خطای ECC H)
- دسترسی آفلاین و سریع به رزروهای هفته با ذخیره‌سازی محلی رمزنگاری‌شده (Room + EncryptedSharedPreferences)
- حالت محافظت بیومتریک اختیاری برای ورود و نمایش کد فراموشی
- هشدار و بررسی خودکار نسخه‌های جدید بر اساس امضای امنیتی
- رابط کاربری کاملاً راست‌به‌چپ (RTL) و فارسی با طراحی مدرن Material Design 3

## 🛠️ نحوه بیلد و ساخت پروژه (Build Instructions)

### پیش‌نیازها:
- JDK 21 یا بالاتر
- Android SDK (API 36 / Android 16)
- ابزار ساخت Gradle

### دستورات بیلد:
```bash
# اجرای تست‌های واحد (Unit Tests)
gradle :app:testDebugUnitTest

# بیلد نسخه دیباگ
gradle :app:assembleDebug

# بیلد نسخه ریلیز امضاشده (نیازمند تنظیم متغیرهای محیطی کلید)
gradle :app:assembleRelease
```

## 🔒 اعتبارسنجی اصالت فایل نصبی (APK Verification)

جهت حصول اطمینان از دست‌نخورده بودن فایل APK دانلود شده:

### ۱. بررسی چک‌سام SHA-256
هش فایل دانلود شده را محاسبه کرده و با جدول هش موجود در فایل `SHA256SUMS.txt` در ریلیزهای گیت‌هاب مطابقت دهید:
```bash
# در لینوکس / مک:
sha256sum SamadFoodQR-*.apk

# در ویندوز (PowerShell):
Get-FileHash -Algorithm SHA256 .\SamadFoodQR-*.apk
```

### ۲. بررسی گواهی امضای رسمی (Signing Certificate Fingerprint)
```bash
apksigner verify --print-certs SamadFoodQR-*.apk
```
اثرانگشت SHA-256 گواهی معتبر سازنده:
```
CB:92:F7:65:BF:89:A7:CC:B7:9F:E7:6A:2B:27:EE:B5:56:73:13:12:38:8F:89:3E:93:34:64:D5:51:C5:7D:7B
```
